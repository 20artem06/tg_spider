# Sport Challenge Bot

Телеграм-бот для спортивного челленджа на двоих в одной группе. Работает на Cloudflare Workers (бесплатный тариф).

## Правила, которые реализует бот

- Каждый день нужно присылать в группу фото или видео/кружок со спортплощадки.
- Отчёт засчитывается **автоматически**, как только зарегистрированный участник присылает фото/видео/кружок.
- Неделя — Пн–Вс, часовой пояс Europe/Moscow.
- Норма — минимум 5 отчётов в неделю. Меньше — проигрыш недели.
- Челлендж стартовал 13.08.2026 (четверг), поэтому первая неделя неполная: в ней 4 дня и норма 3 отчёта.
  Дата старта задаётся константой `CHALLENGE_START` в `src/index.js`; норма неполной недели считается
  пропорционально числу её дней.
- В 21:00 МСК бот напоминает тем, кто ещё не отчитался сегодня.
- В воскресенье в 22:00 МСК бот подводит итог недели и объявляет, если кто-то проиграл.

## Команды

- `/join` — стать участником челленджа (максимум 2 человека на группу)
- `/participants` — список участников
- `/week` — прогресс за текущую неделю (галочки по дням)
- `/month` — статистика за текущий месяц: разбивка по неделям и сколько недель норма выполнена
- `/stats` — общая статистика (сколько отчётов всего, недель выиграно/проиграно, серия побед)
- `/mark 13.08` — отметить прошедший день задним числом (например, если бот тогда ещё не был запущен)
- `/unmark 13.08` — снять отметку
- `/help` — справка

## Деплой на Cloudflare Workers через GitHub

1. **Создай бота в Telegram**: напиши [@BotFather](https://t.me/BotFather), команда `/newbot`, сохрани токен.
   - Обязательно отключи Privacy Mode: `/setprivacy` → выбери бота → `Disable`. Иначе бот не увидит фото/видео в группе без ответа на его сообщение.

2. **Cloudflare Dashboard → Workers & Pages → Create → Connect to Git** и выбери этот репозиторий (ветка, в которую задеплоен код). Билд-команда не нужна — Cloudflare сам подхватит `wrangler.toml` и задеплоит Worker.

3. **Создай KV namespace**: Workers & Pages → KV → Create namespace (например, `sport-challenge-state`). Скопируй его ID и вставь в `wrangler.toml` вместо `REPLACE_WITH_KV_NAMESPACE_ID`, закоммить и запушь — либо привяжи его вручную в настройках Worker'а: Settings → Bindings → Add → KV Namespace, имя binding `STATE`.

4. **Добавь переменные окружения** в настройках Worker'а (Settings → Variables and Secrets):
   - `BOT_TOKEN` — токен от BotFather (Secret)
   - `WEBHOOK_SECRET` — любая случайная строка (Secret), нужна для проверки, что запросы на вебхук идут от Telegram

5. **Пропиши вебхук у Telegram** (замени значения на свои):

   ```bash
   curl "https://api.telegram.org/bot<BOT_TOKEN>/setWebhook?url=https://<your-worker>.workers.dev/webhook&secret_token=<WEBHOOK_SECRET>"
   ```

6. **Добавь бота в вашу группу**, сделай его администратором не обязательно (но лучше добавь, чтобы он гарантированно видел все сообщения при отключённом Privacy Mode это не требуется).

7. В группе оба участника пишут `/join`. Готово — теперь любое фото/видео/кружок от участников будет засчитываться как отчёт.

## Локальная разработка

```bash
npm install
npx wrangler dev
```

Для локальных секретов создай `.dev.vars`:

```
BOT_TOKEN=xxx
WEBHOOK_SECRET=xxx
```
